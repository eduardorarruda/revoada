# Código de conduta

Este é um espaço para construir software juntos. Esperamos de todos:

- Respeito: critique ideias e código, nunca pessoas.
- Paciência com quem está começando — todo mundo já foi iniciante.
- Discussões objetivas, com contexto e boa-fé.

Não são aceitos assédio, discriminação, ataques pessoais, exposição de dados de terceiros ou
qualquer comportamento que torne o ambiente hostil.

Quem mantém o projeto pode editar ou remover comentários, commits e issues que violem estas
regras e, em casos graves ou repetidos, bloquear a participação. Para relatar algo, use o
contato privado indicado em [SECURITY.md](SECURITY.md).
